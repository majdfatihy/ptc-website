# 💰 PTC Website - موقع الربح من الإعلانات

موقع احترافي للربح من مشاهدة الإعلانات وإكمال المهام البسيطة - PTC Website for earning by viewing ads and completing tasks.

## 🎯 المميزات الرئيسية

- ✅ **مشاهدة الإعلانات**: اكسب نقاط من كل إعلان تشاهده
- ✅ **إكمال المهام**: قم بمهام بسيطة واحصل على أجر مقابلها
- ✅ **سحب فوري**: اسحب أرباحك بدون حد أدنى
- ✅ **برنامج إحالة**: احصل على عمولة من كل صديق تحيله
- ✅ **واجهة عربية**: تصميم احترافي وسهل الاستخدام
- ✅ **متجاوب**: يعمل على جميع الأجهزة (ديسكتوب، تابلت، موبايل)

## 🚀 البدء السريع

### المتطلبات
- متصفح ويب حديث
- محرر نصوص (VSCode, Sublime Text, etc.)
- خادم محلي (اختياري)

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/majdfatihy/ptc-website.git

# الدخول للمجلد
cd ptc-website

# فتح الملف في المتصفح
open index.html  # على Mac
start index.html # على Windows
```
